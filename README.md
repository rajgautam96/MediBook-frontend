# 🏥 MediBook – Doctor Appointment & Healthcare Platform

MediBook is a modern healthcare web application designed to simplify the way patients discover doctors and access healthcare services. It provides a digital platform for doctors to showcase their professional profiles, manage their presence, and interact with patients.

The project focuses on building a clean, responsive, and user-friendly healthcare experience using modern web technologies.

## 🚀 Project Overview

MediBook aims to bridge the gap between doctors and patients through a centralized digital healthcare platform.

The frontend is developed using React.js and Vite, providing a fast, responsive, and interactive user experience.

## ✨ Features

- Modern and responsive user interface.
- Doctor profile and portfolio presentation.
- Doctor dashboard interface.
- Professional doctor information display.
- Healthcare-focused UI components.
- Interactive navigation.
- Reusable React components.
- Responsive design for different screen sizes.

## ⚙️ Installation & Setup

Follow these steps to run MediBook locally.

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to Project Directory

```bash
cd MediBook-Frontend
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

### 5. Open in Browser

Visit:

```text
http://localhost:5173
```

## 📦 Build for Production

To create an optimized production build:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```

The production-ready files will be generated inside the `dist` directory.

## 🌐 Deployment

The frontend can be deployed using Netlify.

Deployment steps:

1. Push the project to GitHub.
2. Login to Netlify.
3. Select Import an Existing Project.
4. Connect your GitHub repository.
5. Configure build settings.

**Build Command:**
```bash
npm run build
```

**Publish Directory:**
```text
dist
```

Click Deploy to publish your website.
